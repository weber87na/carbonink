這兩個詞在會議裡經常被混著用，但不該混：**盤查**（碳盤查 / 溫室氣體清單
編製）是企業自己做的那本帳；**查證**（碳查證）是獨立第三方來檢查這本帳
是否實質準確。前者你可以自己做，後者按定義就不能自己做。混淆的代價是
真金白銀 —— 要麼買了沒人要求的確信，要麼到揭露截止時才發現有人要求過。

## 一句話區別

> 企業（或其顧問）依據 ISO 14064-1 / GHG Protocol **編製**清單；
> 有資質的第三方機構依據 ISO 14064-3 **查證**清單並出具查證聲明。

## 一張表對比

| | 碳盤查（清單編製） | 碳查證 |
| --- | --- | --- |
| 誰來做 | 企業自己，常委託顧問機構協助 | 獨立的第三方查證機構 |
| 依據標準 | ISO 14064-1、GHG Protocol、主管部門核算指南 | ISO 14064-3；確信業務另有 ISAE 3410 |
| 輸出 | 清單資料 + 盤查報告 | 查證聲明 / 確信意見 |
| 時點 | 每年年度資料關帳後 | 清單定稿後、揭露之前 |
| 獨立性 | 不要求 | 強制要求 —— 幫你編清單的顧問不能查證自己的成果 |
| 費用構成 | 內部工時 + 資料收集 | 查證人日：邊界規模、抽樣場所數、確信等級 |

確信等級分兩級：**有限確信**（查證方聲明"未發現存在重大錯報的跡象"，
抽樣為主、成本較低）和**合理確信**（正面聲明清單實質準確，測試更深，
接近財務審計強度）。

## 查證員到底查什麼

提前知道清單會被怎麼查，是通過查證最便宜的方式：

- **邊界完整性** —— 法人與場所有沒有漏，排除項有沒有成文理由。
- **資料鏈抽樣** —— 抽若干條資料，要求出示原始憑證：電費單、燃料發票、
  冷媒加註維修保養單。
- **排放係數適用性** —— 每個係數的出處、年份、適用地區是否相符；GWP 版本
  是否一致。
- **復算** —— 抽樣重算，期望落在你報告的數字上。
- **基準年與方法一致性** —— 變更是否說明、是否過了重要性檢驗。

## 什麼情況下查證是強制的

- **碳市場 / MRV 體系** —— 全國碳市場重點排放單位（發電，以及擴容後的
  鋼鐵、水泥、電解鋁等產業）每年接受主管部門組織的第三方查證；歐盟 ETS
  同理。
- **CSRD** —— 歐盟永續報告指令要求對永續聲明做有限確信。
- **加州 SB 253** —— 在加州經營的大型企業範疇一/二揭露分階段引入確信。
- **體系與客戶要求** —— CDP 評分對經查證資料加分；大型採購方越來越多要求
  供應商提供經查證的清單；臺灣對上市櫃公司的強制盤查也配套了分階段的
  查證時程。

都不適用時，查證是可選項 —— 本質是買公信力，在數字第一次對外公開那年
最值。

## 怎麼編一份經得起查證的清單

查證之所以貴，多半是因為清單當初沒按"會被檢查"來編。差別就在**證據鏈**：
每個報告數字都能回溯到原始憑證、活動資料、指名道姓的排放係數和可復現的
計算。具體做法：憑證（帳單、發票、抄表記錄）跟資料存在一起，而不是躺在
某人的電子信箱裡；每一行都記錄係數出處和年份；估算和缺口當場成文，不要事後
補寫。從第一天就按這個紀律建帳 —— 完整步驟見
[ISO 14064-1 清單編製七步](/zh/guides/ghg-inventory/) —— 查證就會從
"考古工程"變成"抽樣練習"。
