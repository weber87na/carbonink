問三位從業者"企業碳盤查該按什麼標準做"，兩個名字都會被提到。誠實的答案是：
ISO 14064-1 和 GHG Protocol 與其說是競爭關係，不如說是處理兩件不同事情的
兩份文件 —— 而且大多數認真做的清單，實際上兩個都在用。下面把區別講透，
不帶供應商濾鏡。

## 兩份文件，兩種職能

**GHG Protocol 企業核算與報告標準**（WRI/WBCSD 出品，免費下載）是一套
*方法學*：教你怎麼定邊界、怎麼理解範疇一/二/三、怎麼算、按什麼原則報告。
全球主流揭露體系 —— CDP、SBTi、CSRD 下的 ESRS、美國證監會與加州的氣候
規則 —— 的核算語言都源自它。

**ISO 14064-1:2018**（付費的 ISO 標準文本）是一套*要求性標準*：一張可審計
的"shall"清單，規定合格的清單和報告必須包含什麼。它的價值在於與
**ISO 14064-3**（查證標準）形成的介面 —— 當招標方、監管者或客戶要求
"按 ISO 14064-1 編製並經第三方查證"時，這個要求是可檢驗的；"我們參照了
良好實踐"則不可檢驗。

## 逐項對比

| | ISO 14064-1:2018 | GHG Protocol 企業標準 |
| --- | --- | --- |
| 發布單位 | ISO | WRI + WBCSD |
| 獲取 | 付費標準 | 免費 PDF |
| 性質 | 可認證的要求性標準（"shall"） | 方法學 + 指南 |
| 排放結構 | 直接排放（類別 1）+ 五類間接排放（類別 2–6） | 範疇 1、2、3（範疇三細分 15 類） |
| 查證介面 | 與 ISO 14064-3 配套設計 | 無配套確信標準 |
| 範疇二處理 | 類別 2；實務中常按 GHGP 指南雙軌報告 | 明確要求 location-based + market-based 雙軌 |
| 典型使用場景 | 招標、認證、亞洲監管（如臺灣上市公司強制盤查）、供應鏈"按 ISO 查證"要求 | CDP、SBTi、CSRD/ESRS、多數自願揭露 |

## 範疇與類別怎麼對應

兩套結構可以乾淨地互相折算，任何方向都不丟資訊：

| GHG Protocol | ISO 14064-1:2018 |
| --- | --- |
| 範疇一 | 類別 1（直接排放） |
| 範疇二 | 類別 2（輸入能源） |
| 範疇三·運輸相關（15 類中的第 4、6、7、9 類） | 類別 3（運輸） |
| 範疇三·採購的貨物與服務、資本貨物、燃料與能源相關、廢棄物（第 1、2、3、5 類） | 類別 4（組織使用的產品） |
| 範疇三·下游：售出產品的使用與報廢、租賃、特許經營、投資（第 10–15 類） | 類別 5–6 |

資料模型建得好，每個排放源只錄一次，兩種口徑都能渲染出來 —— 軟體就該這麼
處理兩套標準（例如碳墨的報告匯出按 ISO 14064-1 結構組織，同時附範疇對應）。

## 什麼時候該以 ISO 14064-1 為框架

- 客戶、招標文件或認證體系**點名 ISO 14064-1** —— 在東亞供應鏈和政府採購裡
  很常見。
- 計畫做**第三方查證**，希望清單直接按查證員將來要對照的要求（ISO 14064-3）
  來搭。
- 所在地監管直接引用 ISO —— 臺灣對上市櫃公司分階段強制盤查是當下最典型的
  例子。

## 什麼時候該以 GHG Protocol 為框架

- 揭露目標是 **CDP、SBTi 或 CSRD/ESRS**，它們的問卷和資料點原生說"範疇"
  語言。
- 需要**免費且夠細的計算指引** —— 範疇二指南和 15 類範疇三標準的"菜譜級"
  細節，ISO 體系裡沒有對應物。
- 剛起步，想先用最通行的詞彙跟同行對標。

## 實務答案：兩個都用

嚴肅清單的標準做法是三層：

1. **用 GHG Protocol 方法學計算** —— 定邊界、範疇二雙軌、按 15 類篩查範疇三。
2. **按 ISO 14064-1 組織和聲明報告** —— 類別 1–6、重要性判定準則、
   不確定性、符合性聲明。
3. 下游有確信需求時，**按 ISO 14064-3 查證**。

這樣做沒有重複勞動：一套資料、兩種呈現，無論對面是 CDP 填報口還是在招標書裡
引用 ISO 的採購官，都能拿到他們要的形狀。完整編製流程見
[ISO 14064-1 清單編製七步](/zh/guides/ghg-inventory/)。
